MAY 2026

Motion Intelligence Lab

Building a real-time telemetry pipeline using a SparkFun 9DoF IMU, Raspberry Pi 4, InfluxDB, and Grafana to capture, store, and visualise live motion data.

Project Overview

The aim of this project was to design and build a complete real-time telemetry system capable of streaming live IMU (Inertial Measurement Unit) data into a time-series database and visualising it through live dashboards.

The project uses a SparkFun 9DoF IMU connected to a Raspberry Pi 4 via serial communication. A Python script running on the Raspberry Pi continuously reads accelerometer and gyroscope data from the sensor, structures the data, and writes it into InfluxDB.

Grafana is then used to query and visualise the incoming telemetry data in real time.

System Architecture

IMU Sensor → Raspberry Pi → Python Data Processing → InfluxDB → Grafana Dashboard

The architecture provides a scalable foundation for robotics, telemetry systems, motion tracking, and sensor analytics applications.

Hardware Used

  • Raspberry Pi 4 Model B
  • SparkFun 9DoF Razor IMU
  • USB Serial Connection
  • MicroSD Card
  • Raspberry Pi OS

Software Stack

  • Python 3
  • PySerial
  • InfluxDB
  • Grafana
  • Linux / Raspberry Pi OS

Setup Process

1. Raspberry Pi Setup

The Raspberry Pi was updated and configured with Python, pip, and virtual environment support. 

sudo apt update
sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv

2. Python Environment

A dedicated Python virtual environment was created for the telemetry pipeline. 

python3 -m venv imu-env
source imu-env/bin/activate
pip install pyserial influxdb

3. InfluxDB Installation

InfluxDB was installed and configured as the project's time-series database. 

sudo apt install -y influxdb
sudo systemctl enable influxdb
sudo systemctl start influxdb

A dedicated database was then created: 

influx

CREATE DATABASE imu_data;
SHOW DATABASES;
EXIT;

4. Grafana Installation

Grafana was installed manually using the official Grafana repositories and signing keys. 

sudo apt install -y wget gnupg2 ca-certificates

wget -qO- https://apt.grafana.com/gpg.key | \
gpg --dearmor | \
sudo tee /usr/share/keyrings/grafana.gpg > /dev/null

echo "deb [signed-by=/usr/share/keyrings/grafana.gpg] \
https://apt.grafana.com stable main" | \
sudo tee /etc/apt/sources.list.d/grafana.list

sudo apt update
sudo apt install -y grafana

Grafana services were then enabled and started: 

sudo systemctl enable grafana-server
sudo systemctl start grafana-server

5. Grafana Dashboard Access

http://raspberrypi.local:3000

Default login: 

Username: admin
Password: admin

InfluxDB Configuration

Grafana was connected directly to InfluxDB using the following configuration:

  • Data Source: InfluxDB
  • Query Language: InfluxQL
  • URL: http://localhost:8086
  • Database: imu_data

Python Data Pipeline

The Python script continuously:

  • Reads serial IMU data
  • Parses CSV sensor values
  • Converts values into structured telemetry data
  • Builds InfluxDB JSON payloads
  • Writes live data into the database
  • Outputs debug information to terminal

Sensor measurements included:

  • accel_x
  • accel_y
  • accel_z
  • gyro_x
  • gyro_y
  • gyro_z

Grafana Dashboard

Grafana dashboards were configured to visualise:

  • Accelerometer X/Y/Z data
  • Gyroscope X/Y/Z data
  • Real-time telemetry updates
  • Live sensor behaviour

Dashboards were configured with refresh intervals between 1–5 seconds for near real-time monitoring.

Engineering Challenges Solved

  • Resolved InfluxDB v1 vs v2 Python client compatibility issues
  • Configured Grafana repositories and signing keys manually
  • Established stable serial communication through /dev/ttyACM0
  • Resolved missing CLI and service configuration issues
  • Designed and validated a structured telemetry pipeline

Current Status

The system is now fully operational with live IMU streaming, InfluxDB time-series storage, and active Grafana dashboards visualising accelerometer and gyroscope telemetry data in real time.

Future Improvements

  • Remote web dashboard access
